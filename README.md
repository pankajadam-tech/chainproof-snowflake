# ChainProof

ChainProof is a Snowflake-native supply-chain metric reconciliation copilot.
It detects cases in which Planning, Procurement, and Logistics use the same KPI name for different calculations. It explains why their values differ, helps a Supply Chain Data Steward approve the correct enterprise definition, publishes the approved definition through a Snowflake Semantic View, and provides governed conversational analytics with visible calculation evidence.

## Hackathon Track

Supply Chain Ontology and Governed Analytics

## Primary User

Supply Chain Data Steward / Operations Analytics Lead

## Secondary Users

- Planning Analyst
- Procurement Analyst
- Logistics Analyst
- Operations Leader

## Core Product Principle
Role controls access.

Persona controls presentation and related information.

The requested semantic metric controls the calculation.

## Initial Domain
Consumer-electronics manufacturing supply chain.

The initial scenario follows laptop components from suppliers through purchase orders and shipments to a manufacturing plant.
