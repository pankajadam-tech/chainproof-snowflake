# ChainProof Submission Package

## Upload or link these artifacts

1. Public GitHub repository
2. Deployed Streamlit application
3. `ChainProof_Hackathon_Presentation.pptx`
4. `ChainProof_Hackathon_Presentation.pdf`
5. Public or unlisted walkthrough video
6. Solution copy from `SUBMISSION_COPY.md`

## Files in this folder

- `ChainProof_Hackathon_Presentation.pptx` - editable deck
- `ChainProof_Hackathon_Presentation.pdf` - stable judge copy
- `SUBMISSION_COPY.md` - portal-ready project text
- `links.md` - canonical submission links
- `presentation/` - editable presentation source and configuration

## Final order of operations

1. Capture the eight required screenshots.
2. Record and upload the walkthrough video.
3. Run `scripts/finalize_submission_links.py` with the final app URL and video URL.
4. Export the updated PPTX to PDF if LibreOffice was not available.
5. Run `scripts/certify_submission_package.sh`.
6. Commit and push.
7. Verify all public links in an incognito browser.
8. Submit through the portal.
